# 避免无谓兼容

## 默认

- **默认不做向后兼容。** 删掉就删掉，改掉就改掉；不要为旧调用方、旧 runner、旧文案多写分支、过滤或双路径。
- 禁止用「兼容一下更稳妥」「过渡期更安全」当默认理由加代码。

## 何时才兼容

仅当**明显会影响用户**时才做兼容，例如：

- 正在进行的任务会失败、卡死或丢结果
- 已保存的数据/配置读不出来，用户必须手工迁移才能继续用
- 对外契约变更会直接打断用户正在依赖的操作

若影响只是日志多一行、提示文案过时、短窗口内旧包偶发无害请求——**直接改，不加兼容。**

## 不确定时

说不清会不会明显影响用户 → 先问用户，不要自行加兼容。
